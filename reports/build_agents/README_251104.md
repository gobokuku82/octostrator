## 🔑 핵심 개념

### 1. Registry 시스템
- **Singleton Pattern**: 전역에서 하나의 인스턴스만 존재
- **Lazy Initialization**: 필요할 때 생성
- **Thread-Safe**: Lock을 사용한 동시성 제어

### 2. Agent 계층
- **BaseAgent**: 모든 Agent의 추상 클래스
- **build_graph()**: 각 Agent의 그래프 구성 메서드
- **invoke()/stream()**: Agent 실행 메서드

### 3. 공유 리소스
- **SubGraph**: 여러 Agent가 공유하는 서브 그래프
- **Tool**: 외부 리소스 접근을 위한 함수
- **평면 구조**: 내부 폴더 없이 평면적으로 관리

### 4. State 관리
- **TypedDict**: State 스키마 정의
- **Annotated**: 리스트 필드의 누적 연산
- **State 전달**: Supervisor → Agent → SubGraph

```bash
mkdir -p backend/app/octostrator/agents/<agent_name>/nodes
```

2. **파일 생성**
```bash
touch backend/app/octostrator/agents/<agent_name>/__init__.py
touch backend/app/octostrator/agents/<agent_name>/agent.py
touch backend/app/octostrator/agents/<agent_name>/state.py
touch backend/app/octostrator/agents/<agent_name>/prompts.py
```

3. **템플릿 복사**
- CODE_TEMPLATES_251104.md에서 Agent 템플릿 복사
- `<AgentName>`, `<agent_name>` 등을 실제 이름으로 변경

4. **등록**
```python
# agents/__init__.py
from .<agent_name>.agent import <AgentName>Agent

def register_all_agents():
    agents = [
        # ...
        ("<agent_name>", <AgentName>Agent),
    ]
```

5. **Supervisor 통합**
```python
# supervisor/nodes/router.py
agent_mapping = {
    # ...
    "<intent_type>": "<agent_name>"
}
```

## 🔧 문제 해결

### 자주 묻는 질문 (FAQ)

**Q1: Registry에 Agent가 등록되지 않습니다.**
```python
# agents/__init__.py에서 register_all_agents() 호출 확인
# 또는 명시적 등록
from .registry import agent_registry
agent_registry.register("my_agent", MyAgent)
```

**Q2: SubGraph를 Agent에서 사용할 수 없습니다.**
```python
# AgentConfig의 subgraphs에 추가
config = AgentConfig(
    # ...
    subgraphs=["rag_graph", "validation_graph"]
)
```

**Q3: Tool이 호출되지 않습니다.**
```python
# Tool Registry 등록 확인
from .registry import tool_registry
tool_registry.register("my_tool", my_tool_func)

# AgentConfig의 tools에 추가
config = AgentConfig(
    # ...
    tools=["my_tool"]
)
```
