## 🔰 LangGraph State란?

### State의 역할

**State = 그래프의 기억 장치**

마치 사람이 대화하면서 "아까 말한 거 기억해?" 하듯이, LangGraph의 노드들도 서로 정보를 주고받아야 합니다. 이 정보를 담는 곳이 **State**입니다.

```python
# 예시: 간단한 State
class MyState(TypedDict):
    user_name: str        # "김철수"
    age: int             # 25
    todos: list          # ["숙제하기", "운동하기"]
```

### State의 흐름

```
Node 1 (계획 생성)
  ↓
State에 plan 저장: {"plan": {"goal": "운동하기", "steps": [...]}}
  ↓
Node 2 (Todo 생성)
  ← State에서 plan 읽기
  ↓
State에 todos 저장: {"todos": [{"task": "준비운동"}, ...]}
  ↓
Node 3 (실행)
  ← State에서 todos 읽기
```

## 🧩 Reducer 함수 개념

### Reducer란?

**Reducer = "어떻게 합칠지" 정하는 규칙**

State가 여러 번 업데이트될 때, **기존 값과 새 값을 어떻게 합칠지** 정하는 함수입니다.

### 왜 필요한가?

```python
# 예시 상황:
# Node 1에서: state["todos"] = ["숙제하기"]
# Node 2에서: state["todos"] = ["운동하기"]

# 질문: 최종 state["todos"]는?
# 옵션 A: ["운동하기"]  ← 덮어쓰기 (기본)
# 옵션 B: ["숙제하기", "운동하기"]  ← 합치기 (Reducer 사용)
```

대부분의 경우, **히스토리를 보관**하려면 "합치기"가 필요합니다!

### 기본 제공 Reducer

LangGraph에는 기본 Reducer들이 있습니다:

#### 1. `add` - 리스트에 추가

```python
from langgraph.graph import add
from typing import Annotated

class State(TypedDict):
    messages: Annotated[list, add]  # add를 사용

# 사용 예시
state = {"messages": ["안녕"]}
# Node 1: state["messages"] = ["반가워"]
# 결과: {"messages": ["안녕", "반가워"]}  ← 추가됨!
```

#### 2. 기본 동작 - 덮어쓰기

```python
class State(TypedDict):
    name: str  # Annotated 없으면 덮어쓰기

# 사용 예시
state = {"name": "철수"}
# Node 1: state["name"] = "영희"
# 결과: {"name": "영희"}  ← 덮어써짐!
```

## 🏷️ Annotated Type 이해하기

### Annotated란?

Python의 **타입 힌트에 메타데이터를 추가**하는 방법입니다.

```python
from typing import Annotated

# 형식: Annotated[타입, 메타데이터1, 메타데이터2, ...]
age: Annotated[int, "나이는 양수여야 함"]
todos: Annotated[list, add, "Todo 리스트"]
```

### LangGraph에서의 사용

```python
from typing import Annotated, TypedDict
from langgraph.graph import add

class State(TypedDict):
    # 일반 필드 (덮어쓰기)
    name: str

    # Reducer 사용 (합치기)
    messages: Annotated[list, add]
    #         ^^^^^^^^  ^^^^  ^^^
    #         타입      메타  Reducer 함수
```

**LangGraph는 Annotated의 두 번째 인자를 Reducer로 인식합니다!**

### 예시 1: 타임스탬프 추가

```python
from datetime import datetime

def add_with_timestamp(existing: list, new: list) -> list:
    """새 항목에 타임스탬프를 추가해서 합치기"""

    # 기존 값이 None이면 빈 리스트로
    if existing is None:
        existing = []

    # 새 항목들에 타임스탬프 추가
    timestamped = []
    for item in new:
        if isinstance(item, dict):
            # dict면 timestamp 필드 추가
            item["timestamp"] = datetime.now().isoformat()
        timestamped.append(item)

    # 기존 + 새 항목
    return existing + timestamped

# 사용
class State(TypedDict):
    actions: Annotated[list, add_with_timestamp]

# 실행
state = {"actions": [{"task": "A"}]}
# Node: state["actions"] = [{"task": "B"}]
# 결과: {
#   "actions": [
#     {"task": "A"},  # 기존
#     {"task": "B", "timestamp": "2025-11-06T09:30:00"}  # 새로 추가
#   ]
# }
```

### 예시 2: 스마트 병합 (중복 제거)

```python
def merge_unique(existing: list, new: list) -> list:
    """중복을 제거하면서 합치기 (ID 기준)"""

    if existing is None:
        existing = []

    # ID를 key로 하는 dict 생성
    merged = {}

    # 기존 항목 추가
    for item in existing:
        item_id = item.get("id")
        if item_id:
            merged[item_id] = item

    # 새 항목 추가/업데이트
    for item in new:
        item_id = item.get("id")
        if item_id:
            merged[item_id] = item  # 같은 ID면 덮어쓰기

    # 리스트로 변환
    return list(merged.values())

# 사용
class State(TypedDict):
    todos: Annotated[list, merge_unique]

# 실행
state = {"todos": [{"id": 1, "task": "A"}]}
# Node: state["todos"] = [{"id": 1, "task": "A_수정"}, {"id": 2, "task": "B"}]
# 결과: {
#   "todos": [
#     {"id": 1, "task": "A_수정"},  # ID 1은 업데이트됨
#     {"id": 2, "task": "B"}        # ID 2는 새로 추가
#   ]
# }
```

### 예시 3: Step 번호 자동 추가

```python
def add_with_step(existing: list, new: list) -> list:
    """Step 번호를 자동으로 부여"""

    if existing is None:
        existing = []

    # 다음 step 번호 계산
    next_step = len(existing) + 1

    # 새 항목에 step 추가
    stepped = []
    for item in new:
        if isinstance(item, dict):
            item["step"] = next_step
            next_step += 1
        stepped.append(item)

    return existing + stepped

# 사용
class State(TypedDict):
    history: Annotated[list, add_with_step]

# 실행
state = {"history": [{"action": "A", "step": 1}]}
# Node: state["history"] = [{"action": "B"}, {"action": "C"}]
# 결과: {
#   "history": [
#     {"action": "A", "step": 1},
#     {"action": "B", "step": 2},  # 자동으로 step 추가
#     {"action": "C", "step": 3}
#   ]
# }
```

## 💡 실전 예시

### 시나리오: Todo Manager

**요구사항**:
1. Todo 추가 시 타임스탬프 자동 기록
2. Step 번호 자동 부여
3. 중복 ID 방지

```python
from typing import Annotated, TypedDict, List, Dict, Any
from datetime import datetime
import uuid

# Reducer 함수
def smart_merge_todos(existing: list, new: list) -> list:
    """
    Todo를 스마트하게 병합:
    - 중복 ID 제거
    - 타임스탬프 추가
    - Step 번호 자동 부여
    """
    if existing is None:
        existing = []

    # 기존 Todo를 dict로 변환 (id 기준)
    todo_dict = {}
    for todo in existing:
        todo_id = todo.get("id")
        if todo_id:
            todo_dict[todo_id] = todo

    # 현재 최대 step 번호
    max_step = max([t.get("step", 0) for t in existing], default=0)

    # 새 Todo 처리
    for todo in new:
        # ID가 없으면 생성
        if "id" not in todo:
            todo["id"] = str(uuid.uuid4())

        # 타임스탬프 추가 (새 항목이거나 업데이트된 경우)
        todo["updated_at"] = datetime.now().isoformat()

        # Step 번호 (기존 항목이면 유지, 신규면 새로 부여)
        todo_id = todo["id"]
        if todo_id not in todo_dict:
            max_step += 1
            todo["step"] = max_step
            todo["created_at"] = todo["updated_at"]
        else:
            # 기존 항목은 step 유지
            todo["step"] = todo_dict[todo_id].get("step", max_step + 1)

        # dict에 추가/업데이트
        todo_dict[todo_id] = todo

    # step 순서로 정렬
    result = list(todo_dict.values())
    result.sort(key=lambda x: x.get("step", 999))

    return result

# State 정의
class TodoState(TypedDict):
    todos: Annotated[list, smart_merge_todos]
    user_query: str
    session_id: str

# 사용 예시
state = {
    "todos": [],
    "user_query": "운동 계획 세워줘",
    "session_id": "abc123"
}

# Node 1: 초기 Todo 생성
state["todos"] = [
    {"task": "준비운동"},
    {"task": "본운동"}
]
# 결과:
# {
#   "todos": [
#     {"id": "...", "task": "준비운동", "step": 1, "created_at": "...", "updated_at": "..."},
#     {"id": "...", "task": "본운동", "step": 2, "created_at": "...", "updated_at": "..."}
#   ]
# }

# Node 2: Todo 추가
state["todos"] = [
    {"task": "마무리 스트레칭"}
]
# 결과:
# {
#   "todos": [
#     {"id": "...", "task": "준비운동", "step": 1, ...},  # 기존 유지
#     {"id": "...", "task": "본운동", "step": 2, ...},    # 기존 유지
#     {"id": "...", "task": "마무리 스트레칭", "step": 3, ...}  # 새로 추가
#   ]
# }

# Node 3: 기존 Todo 수정 (ID로 식별)
first_todo_id = state["todos"][0]["id"]
state["todos"] = [
    {"id": first_todo_id, "task": "준비운동 (수정됨)", "status": "completed"}
]
# 결과:
# {
#   "todos": [
#     {"id": "...", "task": "준비운동 (수정됨)", "step": 1, "status": "completed", "updated_at": "..."},  # 업데이트됨!
#     {"id": "...", "task": "본운동", "step": 2, ...},
#     {"id": "...", "task": "마무리 스트레칭", "step": 3, ...}
#   ]
# }
```

## 📚 Best Practices

### 1. Reducer는 순수 함수로 작성

```python
# ✅ 좋은 예: 부작용 없음
def good_reducer(existing: list, new: list) -> list:
    result = existing.copy() if existing else []
    result.extend(new)
    return result

# ❌ 나쁜 예: 원본 수정
def bad_reducer(existing: list, new: list) -> list:
    existing.extend(new)  # 원본 수정!
    return existing
```

### 2. None 처리 필수

```python
def safe_reducer(existing: list, new: list) -> list:
    # None 체크 필수!
    if existing is None:
        existing = []
    if new is None:
        new = []

    return existing + new
```

### 3. 타입 검증

```python
def typed_reducer(existing: list, new: list) -> list:
    if existing is None:
        existing = []

    # 새 값이 list인지 확인
    if not isinstance(new, list):
        new = [new]

    return existing + new
```

### 4. 성능 고려

```python
# ✅ 좋은 예: dict 사용으로 O(n)
def fast_merge(existing: list, new: list) -> list:
    merged = {item["id"]: item for item in existing}
    for item in new:
        merged[item["id"]] = item
    return list(merged.values())

# ❌ 나쁜 예: 이중 루프로 O(n²)
def slow_merge(existing: list, new: list) -> list:
    for item in new:
        found = False
        for i, existing_item in enumerate(existing):
            if existing_item["id"] == item["id"]:
                existing[i] = item
                found = True
                break
        if not found:
            existing.append(item)
    return existing
```
