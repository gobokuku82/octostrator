# Integrated Authentication + Checkpointer Schema

**작성일**: 2025-11-10
**목적**: 사용자 인증과 LangGraph Checkpointer 통합 스키마
**데이터베이스**: PostgreSQL

---

## 개요

로그인 기능이 있는 멀티유저 챗봇 시스템의 통합 스키마입니다.
- **users**: 사용자 인증 정보
- **chat_sessions**: user_id ↔ thread_id 매핑
- **checkpoints**: LangGraph 대화 상태 저장 (자동 생성)

```dbml
  updated_at timestamp [default: `now()`]
  last_login timestamp

  Note: 'User authentication master table'
}

Table user_sessions {
  id integer [pk, increment]
  user_id integer [not null]
  session_token varchar(255) [unique, not null, note: 'JWT or UUID token']
  refresh_token varchar(255) [unique]
  ip_address varchar(50)
  user_agent text
  expires_at timestamp [not null]
  created_at timestamp [default: `now()`]

  Note: 'Active user sessions (JWT tokens)'
}

Table chat_sessions {
  id integer [pk, increment]
  user_id integer [not null]
  thread_id text [unique, not null, note: 'LangGraph thread_id (FK to checkpoints)']
  session_name varchar(200) [note: 'Auto-generated or user-defined chat title']
  started_at timestamp [default: `now()`]
  last_message_at timestamp
  message_count integer [default: 0]
  is_archived boolean [default: false]

  indexes {
    (user_id, started_at) [name: 'idx_chat_sessions_user']
    thread_id [name: 'idx_chat_sessions_thread']
  }

  Note: 'Maps user_id to thread_id (connects users to LangGraph checkpoints)'
}

// ==================== LangGraph Checkpointer Tables ====================
// Auto-generated by AsyncPostgresSaver.setup()

Table checkpoint_migrations {
  v integer [pk]

  Note: 'Tracks which migrations have been applied'
}

Table checkpoints {
  thread_id text [not null, note: 'Session/conversation thread identifier']
  checkpoint_ns text [not null, default: '']
  checkpoint_id text [not null, note: 'Unique checkpoint identifier']
  parent_checkpoint_id text [note: 'Previous checkpoint ID (for time travel)']
  type text
  checkpoint jsonb [not null, note: 'Actual state data (JSONB)']
  metadata jsonb [not null, default: '{}', note: 'Can store user_id, preferences, etc.']

  indexes {
    (thread_id, checkpoint_ns, checkpoint_id) [pk, name: 'pk_checkpoints']
  }

  Note: 'LangGraph checkpoint storage - Graph execution state'
}

Table checkpoint_blobs {
  thread_id text [not null]
  checkpoint_ns text [not null, default: '']
  channel text [not null]
  version text [not null]
  type text [not null]
  blob bytea

  indexes {
    (thread_id, checkpoint_ns, channel, version) [pk, name: 'pk_checkpoint_blobs']
  }

  Note: 'Channel-level value storage (optimization)'
}

Table checkpoint_writes {
  thread_id text [not null]
  checkpoint_ns text [not null, default: '']
  checkpoint_id text [not null]
  task_id text [not null]
  idx integer [not null]
  channel text [not null]
  type text
  blob bytea [not null]
  task_path text [not null, default: '']

  indexes {
    (thread_id, checkpoint_ns, checkpoint_id, task_id, idx) [pk, name: 'pk_checkpoint_writes']
  }

  Note: 'Pending writes storage (error recovery)'
}

Ref: user_sessions.user_id > users.id [delete: cascade]
Ref: chat_sessions.user_id > users.id [delete: cascade]
```

## 핵심 관계 설명

### 1. users ↔ chat_sessions (1:N)
```
users (1) ──── (N) chat_sessions
```
- 한 사용자가 여러 대화 세션을 가질 수 있음
- `chat_sessions.user_id`로 연결

### 2. chat_sessions ↔ checkpoints (논리적 1:N)
```
chat_sessions.thread_id ───→ checkpoints.thread_id
```
- **주의**: DB 레벨 FK 없음 (LangGraph가 자동 관리)
- 애플리케이션 레벨에서 thread_id로 연결
- 하나의 chat_session이 여러 checkpoint를 가짐 (대화 히스토리)

### 3. checkpoints 내부 관계
```
checkpoints ──── checkpoint_blobs (thread_id 기준)
checkpoints ──── checkpoint_writes (checkpoint_id 기준)
checkpoints.parent_checkpoint_id ──── checkpoints.checkpoint_id (time travel)
```

## 데이터 흐름 예시

### 1. 사용자 로그인 및 대화 시작

```python
# 1. 사용자 로그인
user = await authenticate(email, password)  # users 테이블 조회

# 2. JWT 세션 생성
session_token = create_jwt(user.id)
user_session = UserSession(
    user_id=user.id,
    session_token=session_token,
    expires_at=datetime.now() + timedelta(hours=24)
)
await db.save(user_session)  # user_sessions 테이블 저장

# 3. 대화 시작 (thread_id 생성)
thread_id = f"thread_{uuid.uuid4().hex[:16]}"
chat_session = ChatSession(
    user_id=user.id,
    thread_id=thread_id,
    session_name="새 운동 프로그램 상담"
)
await db.save(chat_session)  # chat_sessions 테이블 저장

# 4. LangGraph 호출 (checkpoints 자동 저장)
result = await graph.ainvoke(
    {"messages": [HumanMessage(content="안녕하세요")]},
    config={"configurable": {"thread_id": thread_id}}
)
# → checkpoints 테이블에 자동 저장됨
```

### 2. 사용자의 대화 목록 조회

```python
# 1. 사용자의 모든 대화 세션 조회
chat_sessions = await db.query(ChatSession).filter(
    user_id=user.id,
    is_archived=False
).order_by(ChatSession.last_message_at.desc()).all()

# 2. 각 대화의 마지막 메시지 미리보기
for session in chat_sessions:
    # checkpoints에서 최신 상태 조회
    state = await graph.aget_state(
        config={"configurable": {"thread_id": session.thread_id}}
    )
    last_message = state.values["messages"][-1].content
    print(f"{session.session_name}: {last_message}")
```

### 3. 특정 대화 이어하기

```python
# 1. chat_session에서 thread_id 가져오기
chat_session = await db.query(ChatSession).filter(id=session_id).first()

# 2. LangGraph로 대화 이어하기 (자동으로 이전 상태 복원)
result = await graph.ainvoke(
    {"messages": [HumanMessage(content="프로그램 수정해줘")]},
    config={"configurable": {"thread_id": chat_session.thread_id}}
)

# 3. chat_session 메타데이터 업데이트
chat_session.last_message_at = datetime.now()
chat_session.message_count += 1
await db.save(chat_session)
```

## 테이블별 역할

### Authentication Layer (인증 계층)

#### users
- **역할**: 사용자 계정 정보 저장
- **생명주기**: 사용자가 회원가입하면 생성, 탈퇴하면 삭제
- **데이터 예시**:
  ```
  id: 123
  email: "user@example.com"
  username: "john_doe"
  role: "user"
  ```

#### user_sessions
- **역할**: 활성 로그인 세션 관리 (JWT 토큰)
- **생명주기**: 로그인 시 생성, 로그아웃 또는 만료 시 삭제
- **데이터 예시**:
  ```
  user_id: 123
  session_token: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  expires_at: "2025-11-11 10:30:00"
  ```

### Chat Management Layer (대화 관리 계층)

#### chat_sessions
- **역할**: 사용자와 대화(thread_id)를 매핑
- **생명주기**: 새 대화 시작 시 생성, 사용자가 삭제하거나 아카이브 시 is_archived=true
- **데이터 예시**:
  ```
  id: 456
  user_id: 123
  thread_id: "thread_a1b2c3d4e5f6g7h8"
  session_name: "근력 운동 프로그램 상담"
  message_count: 15
  ```

### LangGraph Layer (대화 상태 저장 계층)

#### checkpoints
- **역할**: 대화의 실제 상태(State) 저장
- **생명주기**: LangGraph가 자동 관리 (.setup()으로 생성, 대화마다 자동 저장)
- **데이터 예시**:
  ```json
  {
    "thread_id": "thread_a1b2c3d4e5f6g7h8",
    "checkpoint_id": "1ef9a...cbd4",
    "checkpoint": {
      "messages": [...],
      "next": "program_designer",
      "user_info": {...}
    },
    "metadata": {
      "user_id": 123,
      "step": 5
    }
  }
  ```

## SQL 생성 (PostgreSQL)

```sql
-- Authentication Tables
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  email VARCHAR(255) UNIQUE NOT NULL,
  username VARCHAR(100) UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  full_name VARCHAR(100),
  phone VARCHAR(20),
  role VARCHAR(20) DEFAULT 'user',
  is_active BOOLEAN DEFAULT true,
  is_verified BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  last_login TIMESTAMP
);

CREATE TABLE user_sessions (
  id SERIAL PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  session_token VARCHAR(255) UNIQUE NOT NULL,
  refresh_token VARCHAR(255) UNIQUE,
  ip_address VARCHAR(50),
  user_agent TEXT,
  expires_at TIMESTAMP NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE chat_sessions (
  id SERIAL PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  thread_id TEXT UNIQUE NOT NULL,
  session_name VARCHAR(200),
  started_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  last_message_at TIMESTAMP,
  message_count INTEGER DEFAULT 0,
  is_archived BOOLEAN DEFAULT false
);

CREATE INDEX idx_chat_sessions_user ON chat_sessions(user_id, started_at);
CREATE INDEX idx_chat_sessions_thread ON chat_sessions(thread_id);

-- Checkpointer Tables (자동 생성됨 by AsyncPostgresSaver.setup())
-- 직접 생성하지 말고 .setup() 호출할 것!
```

## 구현 가이드

### 1. SQLAlchemy 모델 정의

```python
# backend/database/relation_db/models.py

from sqlalchemy import Column, Integer, String, Boolean, DateTime, Text, ForeignKey
from sqlalchemy.ext.declarative import declarative_base
from datetime import datetime

Base = declarative_base()

class User(Base):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True, autoincrement=True)
    email = Column(String(255), unique=True, nullable=False)
    username = Column(String(100), unique=True)
    password_hash = Column(String(255), nullable=False)
    full_name = Column(String(100))
    phone = Column(String(20))
    role = Column(String(20), default="user")
    is_active = Column(Boolean, default=True)
    is_verified = Column(Boolean, default=False)
    created_at = Column(DateTime, default=datetime.utcnow)
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
    last_login = Column(DateTime)


class UserSession(Base):
    __tablename__ = "user_sessions"

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, ForeignKey("users.id", ondelete="CASCADE"), nullable=False)
    session_token = Column(String(255), unique=True, nullable=False)
    refresh_token = Column(String(255), unique=True)
    ip_address = Column(String(50))
    user_agent = Column(Text)
    expires_at = Column(DateTime, nullable=False)
    created_at = Column(DateTime, default=datetime.utcnow)


class ChatSession(Base):
    __tablename__ = "chat_sessions"

    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(Integer, ForeignKey("users.id", ondelete="CASCADE"), nullable=False)
    thread_id = Column(Text, unique=True, nullable=False)
    session_name = Column(String(200))
    started_at = Column(DateTime, default=datetime.utcnow)
    last_message_at = Column(DateTime)
    message_count = Column(Integer, default=0)
    is_archived = Column(Boolean, default=False)
```

### 3. FastAPI 인증 엔드포인트

```python
# backend/app/api/auth.py

from fastapi import APIRouter, Depends, HTTPException
from passlib.context import CryptContext
import jwt

router = APIRouter(prefix="/auth", tags=["auth"])
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

@router.post("/register")
async def register(email: str, password: str, db: AsyncSession = Depends(get_db)):
    # 1. 비밀번호 해싱
    password_hash = pwd_context.hash(password)

    # 2. 사용자 생성
    user = User(email=email, password_hash=password_hash)
    db.add(user)
    await db.commit()

    return {"message": "User registered successfully"}


@router.post("/login")
async def login(email: str, password: str, db: AsyncSession = Depends(get_db)):
    # 1. 사용자 조회
    user = await db.execute(select(User).where(User.email == email))
    user = user.scalar_one_or_none()

    if not user or not pwd_context.verify(password, user.password_hash):
        raise HTTPException(status_code=401, detail="Invalid credentials")

    # 2. JWT 토큰 생성
    token = jwt.encode({"user_id": user.id}, SECRET_KEY, algorithm="HS256")

    # 3. 세션 저장
    session = UserSession(
        user_id=user.id,
        session_token=token,
        expires_at=datetime.now() + timedelta(hours=24)
    )
    db.add(session)
    await db.commit()

    return {"token": token, "user_id": user.id}
```

### 4. 대화 시작 API

```python
# backend/app/api/chat.py

@router.post("/chat/start")
async def start_chat(
    user_id: int,
    db: AsyncSession = Depends(get_db),
    checkpointer: AsyncPostgresSaver = Depends(get_checkpointer)
):
    # 1. thread_id 생성
    thread_id = f"thread_{uuid.uuid4().hex[:16]}"

    # 2. chat_session 생성
    chat_session = ChatSession(
        user_id=user_id,
        thread_id=thread_id,
        session_name="새 대화"
    )
    db.add(chat_session)
    await db.commit()

    return {"thread_id": thread_id, "session_id": chat_session.id}


@router.post("/chat/{session_id}/message")
async def send_message(
    session_id: int,
    message: str,
    db: AsyncSession = Depends(get_db),
    graph: CompiledGraph = Depends(get_graph)
):
    # 1. chat_session 조회
    chat_session = await db.get(ChatSession, session_id)

    # 2. LangGraph 실행
    result = await graph.ainvoke(
        {"messages": [HumanMessage(content=message)]},
        config={"configurable": {"thread_id": chat_session.thread_id}}
    )

    # 3. chat_session 업데이트
    chat_session.last_message_at = datetime.now()
    chat_session.message_count += 1
    await db.commit()

    return {"response": result["messages"][-1].content}
```

## 보안 고려사항

### 1. 비밀번호 해싱
- ✅ bcrypt 또는 argon2 사용
- ❌ 절대 평문 저장 금지

### 2. JWT 토큰 관리
- ✅ 짧은 만료 시간 (1-24시간)
- ✅ Refresh token으로 갱신
- ✅ HTTPS 전송 필수

### 3. SQL Injection 방지
- ✅ SQLAlchemy ORM 사용 (파라미터화된 쿼리)
- ❌ 문자열 연결로 쿼리 생성 금지

### 4. 권한 관리
- ✅ chat_sessions 조회 시 user_id 검증
- ✅ 다른 사용자의 대화 접근 차단

```python
# 예시: 권한 검증
chat_session = await db.get(ChatSession, session_id)
```

## 결론

✅ **3개 레이어 통합 완료**
- Authentication Layer: users, user_sessions
- Chat Management Layer: chat_sessions
- LangGraph Layer: checkpoints (자동 생성)
