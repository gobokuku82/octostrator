## 개요

Octo Worker는 RESTful API와 WebSocket API를 제공하여 다양한 방식으로 챗봇과 상호작용할 수 있습니다.

### API 타입

| 타입 | 용도 | 프로토콜 |
|------|------|---------|
| REST API | 세션 관리, 상태 조회 | HTTP/HTTPS |
| WebSocket API | 실시간 스트리밍 대화 | WebSocket |

---

## 인증

현재 버전에서는 인증을 요구하지 않습니다. 향후 버전에서 API Key 기반 인증이 추가될 예정입니다.

### 채팅 API

#### 3. 채팅 메시지 전송 (동기)

```http
POST /chat
Content-Type: application/json
```

**설명**: 동기 방식으로 채팅 메시지 전송 및 응답 수신

**Request Body**:
```json
{
  "message": "안녕하세요, 간단한 계약서를 작성해주세요"
}
```

**Response**:
```json
{
  "response": "[최종 응답] 계약서가 작성되었습니다..."
}
```

**에러 응답**:
```json
{
  "detail": "Error processing chat: ..."
}
```

**상태 코드**:
- `200 OK`: 성공
- `500 Internal Server Error`: 처리 중 에러

---

### 세션 관리 API

#### 4. 세션 목록 조회

```http
GET /api/sessions
```

**설명**: 모든 세션 목록 조회

**Query Parameters**:
| 파라미터 | 타입 | 필수 | 설명 |
|---------|------|------|------|
| user_id | string | No | 특정 사용자의 세션만 조회 |
| status | string | No | 특정 상태의 세션만 조회 |

**응답**:
```json
{
  "sessions": [
    {
      "thread_id": "session_001",
      "user_id": "user_123",
      "status": "active",
      "created_at": "2025-11-03T10:00:00Z",
      "updated_at": "2025-11-03T10:30:00Z"
    }
  ],
  "total": 1
}
```

**상태 코드**:
- `200 OK`: 성공

---

#### 5. 세션 상태 조회

```http
GET /api/sessions/{thread_id}
```

**설명**: 특정 세션의 현재 상태 조회

**Path Parameters**:
| 파라미터 | 타입 | 설명 |
|---------|------|------|
| thread_id | string | 세션 ID |

**응답**:
```json
{
  "thread_id": "session_001",
  "status": "completed",
  "state": {
    "messages": [...],
    "user_intent": {...},
    "plan": {...},
    "current_step": 3,
    "is_planning": false,
    "is_executing": false,
    "final_result": "작업 완료"
  },
  "checkpoint_id": "1f0b8754-d0c9-63cd-801c-aaa11472b0f5"
}
```

**상태 값**:
- `waiting_human`: HITL 대기 중
- `in_progress`: 실행 중
- `completed`: 완료됨

**에러 응답**:
```json
{
  "detail": "Session not found: session_001"
}
```

**상태 코드**:
- `200 OK`: 성공
- `404 Not Found`: 세션을 찾을 수 없음
- `500 Internal Server Error`: 서버 에러

### HITL (Human-in-the-Loop) API

#### 7. HITL 세션 재개

```http
POST /api/sessions/{thread_id}/resume
Content-Type: application/json
```

**설명**: interrupt된 세션을 재개

**Path Parameters**:
| 파라미터 | 타입 | 설명 |
|---------|------|------|
| thread_id | string | 세션 ID |

**Request Body**:
```json
{
  "approve": true
}
```

또는

```json
{
  "response": "계약서 내용을 수정해주세요: ..."
}
```

**필드 설명**:
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| approve | boolean | No | true면 자동 승인 (None 전달) |
| response | string | No | 사용자 피드백 텍스트 |

**응답**:
```json
{
  "success": true,
  "message": "Session resumed with auto-approval",
  "state": {...}
}
```

**에러 응답**:
```json
{
  "detail": "Session is not waiting for human input"
}
```

**상태 코드**:
- `200 OK`: 성공
- `400 Bad Request`: 세션이 HITL 대기 중이 아님
- `404 Not Found`: 세션을 찾을 수 없음
- `500 Internal Server Error`: 서버 에러

**Path Parameters**:

### 메시지 프로토콜

#### 클라이언트 → 서버

**메시지 전송**:
```json
{
  "type": "message",
  "content": "안녕하세요, 계약서를 작성해주세요"
}
```

**HITL 응답**:
```json
{
  "type": "human_response",
  "approve": true
}
```

또는

```json
{
  "type": "human_response",
  "response": "수정사항: ..."
}
```

---

#### 서버 → 클라이언트

**이벤트 타입**:

1. **연결 확인**
```json
{
  "type": "connection",
  "session_id": "session_001",
  "message": "WebSocket 연결됨"
}
```

2. **노드 시작**
```json
{
  "event": "on_chain_start",
  "node": "intent_understanding",
  "data": "Intent Understanding 시작..."
}
```

3. **노드 완료**
```json
{
  "event": "on_chain_end",
  "node": "planning",
  "data": {
    "plan": {...}
  }
}
```

4. **HITL 요청**
```json
{
  "type": "hitl_request",
  "message": "계약서 작성을 진행하시겠습니까?",
  "context": {...}
}
```

5. **최종 응답**
```json
{
  "type": "final",
  "content": "[최종 응답] 작업이 완료되었습니다..."
}
```

6. **에러**
```json
{
  "type": "error",
  "error": "처리 중 에러가 발생했습니다: ..."
}
```

### WebSocket 연결 예제 (JavaScript)

```javascript
const ws = new WebSocket('ws://localhost:8000/ws/my_session_001');

ws.onopen = () => {
  console.log('WebSocket 연결됨');

  // 메시지 전송
  ws.send(JSON.stringify({
    type: 'message',
    content: '안녕하세요'
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('받은 메시지:', data);

  // HITL 요청 처리
  if (data.type === 'hitl_request') {
    // 사용자 확인 후 승인
    ws.send(JSON.stringify({
      type: 'human_response',
      approve: true
    }));
  }
};

ws.onerror = (error) => {
  console.error('WebSocket 에러:', error);
};

ws.onclose = () => {
  console.log('WebSocket 연결 종료');
};
```

### WebSocket 연결 예제 (Python)

```python
import asyncio
import websockets
import json

async def chat():
    uri = "ws://localhost:8000/ws/my_session_001"

    async with websockets.connect(uri) as websocket:
        # 메시지 전송
        await websocket.send(json.dumps({
            "type": "message",
            "content": "안녕하세요"
        }))

        # 응답 수신
        async for message in websocket:
            data = json.loads(message)
            print(f"받은 메시지: {data}")

            # HITL 처리
            if data.get("type") == "hitl_request":
                await websocket.send(json.dumps({
                    "type": "human_response",
                    "approve": True
                }))

asyncio.run(chat())
```

### 예제 3: WebSocket 실시간 대화

```python
import asyncio
import websockets
import json

async def interactive_chat():
    uri = "ws://localhost:8000/ws/interactive_session_001"

    async with websockets.connect(uri) as ws:
        print("연결됨")

        # 메시지 전송
        await ws.send(json.dumps({
            "type": "message",
            "content": "간단한 계약서를 작성해주세요"
        }))

        # 실시간 스트리밍 응답 수신
        async for message in ws:
            data = json.loads(message)

            if data.get("type") == "connection":
                print(f"세션 ID: {data['session_id']}")

            elif data.get("event") == "on_chain_start":
                print(f"▶ {data['node']} 시작")

            elif data.get("event") == "on_chain_end":
                print(f"✓ {data['node']} 완료")

            elif data.get("type") == "hitl_request":
                print(f"\n[승인 요청] {data['message']}")
                user_input = input("승인하시겠습니까? (y/n): ")

                await ws.send(json.dumps({
                    "type": "human_response",
                    "approve": user_input.lower() == 'y'
                }))

            elif data.get("type") == "final":
                print(f"\n[최종 응답]\n{data['content']}")
                break

            elif data.get("type") == "error":
                print(f"에러: {data['error']}")
                break

asyncio.run(interactive_chat())
```
