## 개발 환경 설정

### 요구사항

- Python 3.11+
- PostgreSQL 13+
- uv (Python 패키지 관리자)
- Git

### 설치

#### 1. 저장소 클론

```bash
git clone <repository-url>
cd Octo_worker/beta_v002
```

#### 2. Python 가상 환경 및 의존성 설치

```bash
# uv로 의존성 동기화
uv sync
```

#### 3. PostgreSQL 데이터베이스 생성

```bash
# PostgreSQL 접속
psql -U postgres

# 데이터베이스 생성
CREATE DATABASE octo_chatbot;

# 사용자 생성 (선택사항)
CREATE USER octo_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE octo_chatbot TO octo_user;
```

#### 4. 환경 변수 설정

`.env` 파일을 생성하고 다음 내용을 입력합니다:

```bash

OPENAI_API_KEY=sk-your-openai-api-key

# PostgreSQL
POSTGRES_URL=postgresql://postgres:your_password@localhost:5432/octo_chatbot

# System
SYSTEM_DEBUG=True
SYSTEM_API_HOST=0.0.0.0
SYSTEM_API_PORT=8000

# CORS
SYSTEM_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:5173
```

#### 5. 서버 실행

```bash
# 개발 모드로 서버 실행
uv run python run_server.py
```

## 새 에이전트 추가

새로운 에이전트를 추가하려면 다음 단계를 따르세요.

### 1. 에이전트 파일 생성

`backend/app/octostrator/agents/` 디렉토리에 새 파일을 생성합니다.

**예제: `email_agent.py`**

```python
"""Email Agent

이메일 발송을 담당하는 에이전트
"""
from typing import Dict, Any
from langchain_openai import ChatOpenAI
from langchain_core.messages import AIMessage

async def execute_email_agent(state: Dict[str, Any]) -> Dict[str, Any]:
    """Email Agent 실행

    Args:
        state: 현재 상태

    Returns:
        업데이트된 상태
    """
    # 현재 단계 정보 가져오기
    plan = state["plan"]
    current_step = state["current_step"]
    step_info = plan["steps"][current_step]
    task = step_info["task"]

    # LLM 초기화
    llm = ChatOpenAI(model="gpt-4", temperature=0)

    # 프롬프트 구성
    prompt = f"""
    다음 이메일 발송 작업을 수행해주세요:

    작업: {task}

    이메일 내용을 작성하고 발송 정보를 제공해주세요.

    응답 형식:
    - 수신자: [이메일 주소]
    - 제목: [이메일 제목]
    - 본문: [이메일 본문]
    """

    # LLM 호출
    response = await llm.ainvoke(prompt)

    # 메시지 추가
    state["messages"].append(
        AIMessage(content=f"[Email Agent] {response.content}")
    )

    # 다음 단계로
    state["current_step"] += 1

    return state
```

### 예제: 데이터 검증 노드

```python
"""Data Validation Node

데이터 유효성 검증 노드
"""
from typing import Dict, Any
from langchain_core.messages import AIMessage
from backend.app.octostrator.supervisor.state import SupervisorState

async def validate_data_node(state: SupervisorState) -> SupervisorState:
    """데이터 검증 노드

    사용자 입력 데이터를 검증하고 오류가 있으면 알림
    """
    messages = state["messages"]
    last_message = messages[-1].content

    # 간단한 검증 로직
    errors = []

    if len(last_message) < 5:
        errors.append("메시지가 너무 짧습니다")

    if not any(char.isalnum() for char in last_message):
        errors.append("유효한 문자가 없습니다")

    # 검증 결과 메시지 추가
    if errors:
        validation_msg = f"[Validation] 오류 발견: {', '.join(errors)}"
    else:
        validation_msg = "[Validation] 데이터 검증 통과"

    state["messages"].append(AIMessage(content=validation_msg))

    return state
```

async def create_checkpointer(conn_string: str = None, pool_size: int = 10):
    """Checkpointer 생성 with connection pooling"""
    # 연결 풀 크기 설정
